# LA Neighborhood Report

A phone-friendly page to report trash, illegal dumping, and encampments in Los Angeles Council Districts 5 and 11.

Open the site, add a photo or location, and tap **Open in my email**. That opens a pre-filled message in your own mail app (attach the photo there). **File with MyLA311** links to [myla311.lacity.gov](https://myla311.lacity.gov).

This page stores and sends nothing. Lookups run in your browser; the photo stays on your device.

## GitHub Pages

1. Open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Set the branch to **main** and the folder to **/ (root)**, then save.

Pages will publish this `index.html`. `.nojekyll` is included so GitHub serves the file as-is.
